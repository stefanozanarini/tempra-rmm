Agent keys are generated on the PC; certificates last 90 days and renew with a new key.

The builder passphrase is asked at each use and never stored by the console.

Revocation disconnects an agent immediately, even mid-session.

Tempra RMM8
Consoles that want the strictest model keep module and release keys offline: then even a fully compromised console cannot publish code to agents. With keys in the builder, an attacker would also need the passphrase, which is entered per operation.
