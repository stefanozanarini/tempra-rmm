Threat model

Each threat has a named mitigation

ThreatMitigation
Console compromisedPer-command MFA checked by a separate signer; keys encrypted or offline
DMZ host compromisedRelay without DB credentials or CA key; the LAN side opens the tunnel
Rogue enrollmentExpiring, use-limited tokens; new agents wait for approval
Man-in-the-middlemTLS with a pinned private root CA; system trust store never used
Tampered module or packageEd25519 signature and SHA-256 checked before anything runs
Job replayNonce, expiry and agent id signed; persistent replay cache
Operator abuseRoles, per-command MFA, immutable hash-chained audit log

Supply chain: few dependencies; govulncheck, gosec, staticcheck and race detector in CI.
