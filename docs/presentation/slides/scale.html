Built for service providers

One central console, many customers, control stays local

Multi-tenant

A tenant id in every row, API and job, enforced by PostgreSQL row-level security.

Federation

The customer console dials out to the central one over a pinned link. Everything doable locally is doable centrally.

Customer in charge

Commands still signed by the customer’s signer with the operator’s MFA. Role cap, suspend, local audit.

Only a summary syncs every 5 minutes; pages are fetched live. The customer console stays fully autonomous when the link is down.

Tempra RMM17
The central console never holds customer signing keys and cannot create commands or policies by itself. Every action appears in the customer's audit log as operator so-and-so via central console.
