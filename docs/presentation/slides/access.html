Roles add up. The signer copies the OS family into every job, and the agent refuses a job meant for the other family.

Scopes

By site or computer group

An operator, or an Entra security group, is limited to some sites or groups. Checked on commands, approvals, revocations, site moves and provisioning.

Only OpenRMM.Admin can change a site or group that a scope depends on.

Tempra RMM10
The OS-family limit comes from the step-up token, so it is enforced by the signer and by the agent too, not only by the console. Scopes are set on the Scopes page under Administration. Settings, tokens, policies, agent versions, installers and federation links stay with OpenRMM.Admin.
