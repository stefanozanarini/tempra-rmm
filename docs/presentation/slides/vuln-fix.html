A CVE, end to end

Open a CVE, see who is affected, approve the fix

On the CVE page

  • Badges: actively exploited (CISA KEV), used in ransomware, CVSS
  • Links to Microsoft and NVD
  • Affected computers, installed version, fix
  • The prepared action for exactly those computers
  • Per computer: its CVEs, version installed and fix

The prepared fix

ProductAction
WindowsInstall security and critical updates
Applicationswinget upgrade, or deploy from the library
LinuxUpgrade the affected packages

The operator reviews the computer list and approves once with MFA.
